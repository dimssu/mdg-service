# Architecture decision records

Each file records one decision: what forced it, what was chosen, and what it costs. They are history.
A decision is never rewritten. When it changes, the old file gets a dated status line, a banner or a
"Superseded in part by" line, and the new decision gets a new number.

Three rules:

- Numbers are never reused. The next free number is **0022**.
- **"ADR 0009" means only the landing assistant.** The audit-logging record was first filed as 0009,
  then renumbered **0020** in October 2026. Dozens of code files cite 0009 by section.
- Code comments point into section numbers (for example "ADR 0009 §5"). Do not renumber the sections
  of an ADR that code cites.
